# @kagami-arch-jp/sptc-tools

AIを活用した4つの実用ツールを提供するCLIアプリケーションです。

**Gitリポジトリ**: https://github.com/kagami-arch-jp/sptc-tools

## 機能概要

### 1. Image Generator（画像生成）
テキストプロンプトから画像を生成するツールです。
- プロンプト入力による画像生成
- 画像サイズ（512x512, 768x768等）の選択
- 生成ステップ数の設定
- 生成進捗のリアルタイム表示
- 生成画像のプレビュー

### 2. Writer（執筆アシスタント）
AIを活用した執筆支援ツールです。
- 複数セッションの管理
- AIによる文章提案・補完
- Markdownプレビュー機能
- キーボードショートカット対応
- ルール設定によるカスタマイズ

### 3. TodoList（タスク管理）
タスクの作成・管理を行うツールです。
- タスクの新規作成（テキスト入力、カラー設定）
- ドラッグ＆ドロップによる並べ替え
- 2秒長押しによるタスク完了
- 完了時の紙吹雪エフェクト（Confetti）
- 完了済みタスクの履歴表示
- 期間フィルタリング機能

### 4. Mr.ChatBot（チャットボット）
会話練習のためのチャットボットです。
- 複数セッションの管理
- ロール（役割）選択機能
- リアルタイムチャット
- セッションごとのタイトル編集

## 技術スタック

- **フロントエンド**: React, JSX, SCSS
- **ビルドツール**: Webpack 5
- **状態管理**: react-cross-component-state
- **AI機能**: ollama（外部サービス）
- **その他**: dnd-kit（ドラッグ＆ドロップ）, canvas-confetti, Markdownレンダリング

## 必要条件

- Node.js 22.22.1以上
- [ollama](https://ollama.com) のインストールと起動（AI機能を使用する場合）

## インストール

```bash
# グローバルインストール
npm install -g sptc-tools
```

## 使い方

### CLIツールとして使用

グローバルインストール後は、`tool` コマンドが使用可能になります：

```bash
tool
```

ローカルインストールの場合は、npxを使用します：

```bash
npx sptc-tools
```

実行後、開発サーバーが http://127.0.0.1:9090 で起動します。

## ダークモード対応

各ツールはダークモードに対応しています。アプリケーション全体のテーマ設定に連動します。
