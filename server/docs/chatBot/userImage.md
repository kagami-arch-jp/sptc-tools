# 需求

请根据会话历史记录和上次的**用户画像**，总结新的**用户画像**

# 输出要求

- 使用markdown列表格式
- 输出纬度
  - 用户基本信息，如名字，昵称，年龄，性别等
  - 工作经历和学校经历
    **尽可能完整但使用简洁的语句记录**
  - 现在工作情况，在职还是离职
    **如果离职了，上次大概什么时间离职的**
  - 性格
  - 兴趣
  - 喜欢的和厌恶的东西等
  - 技能
  - 最近遇到的困难**且还没解决的**
  - 最近关注的事情
  - 长处短处
  - 最近的收获
  - 曾经解决的难题，解决方案的亮点等
- 每个纬度描述文字尽可能简短，但必须保留**关键词**，尤其是关键场所的名字，地点，时间，主要经历等
- 用户是在不断成长的，所以**如果某个特征与之前的画像不同，以新的为准**
- 请使用**英文**输出用户画像
- 请直接输出**用户画像**的描述
  **禁止输出任何其他无关内容**
