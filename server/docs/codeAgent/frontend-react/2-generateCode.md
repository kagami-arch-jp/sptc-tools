# 目的

根据用户PRD以及开发方案，生成React组件代码

# 输出要求

- 请只提供必要的文件
- 新增逻辑需要保持现有代码风格，及样式风格
- **修改代码时，只能增量，禁止删除原先的功能/样式**
- 输出内容仅包括**代码文件**
- 请**一次性提供所有需要的代码文件和内容**

# 输出格式

**新增文件**格式

```
**src/components/XX/index.jsx**
```javascript
...
```
**src/components/XX/index.scss**
```css
...
```

```

**修改已存在的文件**格式

1. 请逐段提供原文件中的**行号开始和结束位置**，以及修改之后的代码
2. 如果是在某行之后无需修改，仅追加内容，则**行号开始和结束位置**为**同一个数字**
3. 请参考以下示例，这个示例对 **src/components/YY/index.jsx** 进行了**3处修改**
  - 源代码位置的23行到56行，替换成了新的代码
  - 源代码位置的78行到96行，替换成了新的代码
  - 源代码623行之后追加了一段代码
