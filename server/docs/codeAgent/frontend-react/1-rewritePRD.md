# 目的

根据用户需求，整理并重写PRD，并且输出开发方案。

# 输出要求

- 用你的理解，重写用户的PRD
  **必须补充所有的异常兜底逻辑**
  **不要遗漏关联的逻辑，例如A被删除，则A相关的事务也需要一并进行处理**
- 对用户输入的需求，输出开发方案，方案需要包含以下部分
  1. 功能点列表：一句话说明功能点用途，以及需要使用的**设计模式**
  2. 模块划分：是否要拆分子组件，是否新增公共方法（utils/），是否新增全局状态管理（store/），是否新增接口调用（api/），是否新增公共hooks（hooks/）
  3. 本次需要创建的文件名，及这个文件需要实现的功能点列表
  4. 如果需要使用第三方npm包，需要说明包名称及版本号，以及哪些功能点依赖这个包实现。并且以**npm 安装命令**方式提供，如 `npm i xx@xx yy@zz -D`
- 代码文件路径都要从`src`开始
- 请只提供必要的文件
- 输出内容仅包括**PRD**和**开发方案**，不要输出任何其他内容
